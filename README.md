# DoseEgg — prototypes & design

A medication and context journal for people living with Young Onset Parkinson's disease.

Built around one idea: logging should feel like *contributing to your day*, not switching
into an app.

**[Open the prototypes →](https://tutuseagull.github.io/dose-egg-public/)**  Best viewed on a phone.

## What's here

- `prototypes/` — clickable HTML prototypes, including rejected directions kept as marked
  examples
- `glossary.html` — Parkinson's and product vocabulary
- `research.html` — studies and evidence behind the design
- `reference-products.html` — what this product learns from, and what it moves away from
- `open-questions.html` — what's still undecided
- `design-tokens.html` — colour, type and spacing foundations

## About the data

Every prototype uses sample data. **No real patient data appears anywhere in this
repository.** Research notes, design constraints, participant material and the project's
decision log are kept in a separate private repository.

## How this repo is produced

This is a generated snapshot, not a working repo. Files are built from the private
repository by an allowlist, with an automated check that blocks the build if participant
content appears. Do not edit files here directly — edits belong upstream.

## Status

Pre-MVP, in active design. Updated at milestones.
