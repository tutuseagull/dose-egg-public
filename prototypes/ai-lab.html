Setup — how the two engines work

In-browser (WebLLM): downloads a small open model (Qwen 2.5, 1.5B) once (~950 MB) and runs it inside this page with WebGPU. Nothing you type ever leaves this device. Needs a recent Mac/PC and Chrome, Edge, or Safari 18+. Phones mostly not supported yet.

Ollama (this computer): better quality, needs Ollama installed. In Terminal: brew install ollama, then ollama pull qwen2.5:3b. To let this page talk to it, start it with OLLAMA_ORIGINS="*" ollama serve. Also private — the model runs on your machine, no internet needed.

Tip: if the page is opened as a local file and Ollama refuses to connect, serve the folder instead: cd prototypes && python3 -m http.server 8000, then open http://localhost:8000/ai-lab.html.
